## RuStore — магазин приложений

Проект, созданный в процессе обучения на курсе от VK. 

## Описание приложения

Приложение состоит из двух экранов: главный со списком приложений и второй, содержащий детальную информацию о приложении.

При нажатии на элемент списка осуществляется переход к экрану выбранного приложения. 

Окно детальной информации приложения: 

- Реализация перехода между страницами <-
- Функциональность «WishList» (при нажатии на кнопку, она меняет цвет + уведомление о добавлении/удалении в список избранного, данные сохраняются в БД)
- При нажатии на кнопки, чья функциональность еще не реализована, всплывает уведомление «В процессе разработки»

* Данные приложения подгружаются с API (использование библиотеки Retrofit для реализации get-запросов)

* В приложении реализована работа с базой данных Room (информация о карточке приложения берется из БД, а если там нет записи, то запрос отправляется на сервер и затем полученные данные сохраняются в БД)

* Для RepositoryImpl, Mappers и UseCases добавлены unit-тесты

* Написан список Epic-ов для декомпозиции проекта

* Из проекта создан apk-файл 

## Технология разработки программного продукта

Язык программирования — Kotlin. Среда разработки: Android Studio.

Подход к программированию — использование Jetpack Compose.

Использование принципов Clean Archeticture. 

Работа с API для загрузки данных приложения. 

Хранение данных с помощью БД Room.
